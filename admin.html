Connexion à GitHub

Dépôt : BrainlssTV / lspd-portail. Seul un accès GitHub autorisé à écrire dans ce dépôt permet de publier.

Première connexion : créer une clé d’accès
  1. Ouvrez la création d’un jeton GitHub ↗.
  2. Nommez-le « Éditeur LSPD », choisissez une expiration et le propriétaire BrainlssTV.
  3. Dans « Repository access », sélectionnez « Only select repositories », puis « lspd-portail ».
  4. Dans « Repository permissions », donnez à « Contents » l’accès « Read and write ».
  5. Générez le jeton, copiez-le et collez-le ci-dessous. Ne le partagez pas et ne l’ajoutez jamais aux fichiers du site.

La clé reste uniquement en mémoire dans cet onglet. Elle est effacée à la déconnexion ou au rechargement.

Enregistrer une fiche prépare un brouillon dans cet onglet. « Publier les modifications » l’enregistre sur GitHub. Le site public se met ensuite à jour via GitHub Pages.
