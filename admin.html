Configurer mon accès GitHub
  1. Ouvrez la création d’une clé GitHub ↗.
  2. Choisissez une expiration et le propriétaire BrainlssTV.
  3. Dans Repository access : Only select repositories → lspd-portail.
  4. Dans Repository permissions : Contents → Read and write.
  5. Générez la clé et collez-la ici. Ne l’ajoutez jamais aux fichiers du site.

La clé reste en mémoire dans cet onglet, sans enregistrement sur votre ordinateur. Le mode essai permet de préparer un brouillon et de l’exporter.
